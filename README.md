# Employee Hours

Angular application that shows employees' total time worked in a table and a pie chart.

## Getting started

Install the dependencies with `npm install`, then replace `MY_API_KEY` in `src/environments/environment.ts` with your API key. Start the application with `npm start` and open [http://localhost:4200](http://localhost:4200). It has to run on port 4200, because the API rejects browser requests from other local ports.
