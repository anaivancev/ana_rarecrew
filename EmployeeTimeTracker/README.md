# Employee Time Tracker

## Getting started

1. Install the [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

2. Open PowerShell and go to the project folder:

   ```powershell
   cd EmployeeTimeTracker
   ```

3. Set your API key. It is only kept for the current terminal window:

   ```powershell
   $env:ApiSettings__ApiKey = "your_api_key"
   ```

4. Start the application:

   ```powershell
   dotnet run
   ```

5. Open [http://localhost:5290](http://localhost:5290) in your browser.

6. To stop the application, press `Ctrl + C` in the terminal.
